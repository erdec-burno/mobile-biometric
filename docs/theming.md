# Темизация

Приложение поддерживает светлую и тёмную темы и автоматически следует системной настройке устройства или браузера.

## Определение активной темы

В `app.json` установлено `"userInterfaceStyle": "automatic"`. React Native получает текущую схему через `useColorScheme()`:

- `light` — светлая тема;
- `dark` — тёмная тема;
- `unspecified` — тема не определена; в прикладной палитре используется светлая тема как запасной вариант.

На вебе `src/hooks/use-color-scheme.web.ts` до клиентской гидратации всегда возвращает `light`. После гидратации хук читает фактическую схему браузера. Это предотвращает расхождение между статическим HTML и первым клиентским рендером.

## Палитра приложения

Все прикладные цвета определены в `src/constants/theme.ts` в объекте `Colors`. Для каждой темы доступны одинаковые семантические ключи:

| Ключ | Назначение |
| --- | --- |
| `text` | Основной цвет текста |
| `background` | Основной фон экрана |
| `backgroundElement` | Фон карточек, панелей и элементов |
| `backgroundSelected` | Фон выбранного элемента |
| `textSecondary` | Второстепенный текст |

Хук `src/hooks/use-theme.ts` выбирает `Colors.light` или `Colors.dark` и возвращает активную палитру. Любое значение схемы, кроме `dark`, безопасно обрабатывается как светлая тема.

## Синхронизация после возврата в приложение

`ColorSchemeProvider` из `src/hooks/use-color-scheme.ts` оборачивает корневой layout. Он хранит активную схему в React context и при переходе `AppState` в `active` заново читает `Appearance.getColorScheme()`.

Это покрывает сценарий, когда пользователь меняет светлую или тёмную тему в настройках телефона, пока приложение свёрнуто: при возврате экран и вкладки сразу получают актуальные цвета. На вебе провайдер сохраняет существующее поведение безопасной гидратации.

На Android `MainActivity` также передаёт изменение конфигурации в React Native через `onConfigurationChanged`; флаг `uiMode` уже указан в `AndroidManifest.xml`. Оба условия необходимы для обработки системной темы без перезапуска Activity.

## Компоненты с темой

Для обычного интерфейса следует использовать общие компоненты:

- `ThemedView` из `src/components/themed-view.tsx` задаёт `backgroundColor`. По умолчанию применяется `background`; вариант выбирается через, например, `type="backgroundElement"`.
- `ThemedText` из `src/components/themed-text.tsx` задаёт цвет текста. По умолчанию это `text`; для другого семантического цвета используется `themeColor`, например `themeColor="textSecondary"`.

Если компоненту нужен цвет вне этих обёрток, он может вызвать `useTheme()` и использовать, например, `theme.background` или `theme.text`.

## Навигация и вкладки

Корневой layout (`src/app/_layout.tsx`) передаёт в `ThemeProvider` Expo Router одну из стандартных навигационных тем: `DefaultTheme` для светлой схемы и `DarkTheme` для тёмной.

Компоненты вкладок самостоятельно используют прикладную палитру `Colors`:

- `src/components/app-tabs.tsx` — нативные вкладки;
- `src/components/app-tabs.web.tsx` — вкладки для веба.

## Важный нюанс

В проекте существуют два согласованно переключаемых, но независимых источника цветов:

1. `Colors` — прикладная палитра для экранов, текста и вкладок.
2. `DefaultTheme` / `DarkTheme` Expo Router — палитра навигации.

При изменении фирменных цветов при необходимости обновляйте оба источника, чтобы навигация и содержимое приложения сохраняли единый внешний вид.
